# /tmux-setup - Intelligent Project Setup Command

> Analyzes your system and proposes optimal tmux-claude configuration

## Usage

```
/tmux-setup
/tmux-setup --scan       # Rescan projects
/tmux-setup --ports      # Configure dev server ports
/tmux-setup --aliases    # Regenerate aliases only
```

## What This Command Does

1. **Scans** common directories for projects
2. **Detects** project type (Next.js, React, Node, Python, Go, etc.)
3. **Suggests** aliases based on project names
4. **Assigns** ports for dev servers (avoiding conflicts)
5. **Creates** complete shell configuration
6. **Validates** the setup

## Implementation

When user invokes `/tmux-setup`, execute this workflow:

### Step 1: Scan Projects

```bash
# Scan common directories
DIRS="$HOME/projects $HOME/code $HOME/dev $HOME/work $HOME/workspace"
DIRS+=" $HOME/Projects $HOME/Code $HOME/Dev $HOME/Work"
DIRS+=" $HOME/repos $HOME/src $HOME/Sites"
DIRS+=" $HOME/VibeCoding/work $HOME/VibeCoding/clients $HOME/VibeCoding/agentic-os"

for dir in $DIRS; do
    if [ -d "$dir" ]; then
        find "$dir" -maxdepth 2 -name "package.json" -o -name ".git" -o -name "Cargo.toml" -o -name "go.mod" 2>/dev/null
    fi
done
```

### Step 2: Detect Project Types

For each project found, detect type:

| File | Type | Default Port Range |
|------|------|-------------------|
| `package.json` + `next.config.*` | Next.js | 3000-3999 |
| `package.json` + `vite.config.*` | Vite | 5173-5999 |
| `package.json` | Node.js | 4000-4999 |
| `Cargo.toml` | Rust | 8000-8999 |
| `go.mod` | Go | 8080-8099 |
| `requirements.txt` | Python | 8000-8099 |
| `app.json` + `expo` | Expo | 8081 |

### Step 3: Generate Alias Names

Rules for alias names:
1. Lowercase the project folder name
2. Replace spaces with dashes
3. Remove special characters
4. Keep it short (max 12 chars)
5. Avoid collisions

Examples:
- `MyProject` -> `c-myproject`
- `DentistryGPT` -> `c-dent`
- `Gluten-Libre` -> `c-gluten`
- `Formation-AI` -> `c-formation`

### Step 4: Assign Ports

Use this port allocation strategy:

| Category | Port Range | Example |
|----------|-----------|---------|
| Personal/Work | 33001-33999 | Kommu: 33001 |
| Clients | 22001-22999 | DentistryGPT: 22002 |
| Internal/Tools | 11001-11999 | LifePixels: 11001 |
| Default | 3000-3999 | Auto-assigned |

Check for conflicts:
```bash
ss -tln | grep ":PORT "
```

### Step 5: Present Configuration

Show the user a table:

```
Detected Projects
-----------------
Alias          Project         Path                              Port   Type
c-myproject    MyProject       /home/user/projects/myproject     3001   Next.js
c-backend      Backend         /home/user/projects/backend       4001   Node.js
c-api          API-Server      /home/user/code/api               8080   Go
```

Ask for confirmation or modifications.

### Step 6: Generate Shell Config

Create the aliases block:

```bash
# === tmux-claude ===
# Auto-generated by /tmux-setup

# Global
alias ts='tmux-select'
alias tps='tmux ls 2>/dev/null || echo "No sessions"'
alias c-home='tmux-project Home $HOME --no-claude'

# Projects
alias c-myproject='tmux-project MyProject /home/user/projects/myproject'
alias c-backend='tmux-project Backend /home/user/projects/backend'
alias c-api='tmux-project API /home/user/code/api'

# Port mapping (used by tmux-project)
export TMUX_CLAUDE_PORTS='{"myproject":3001,"backend":4001,"api":8080}'

# === end tmux-claude ===
```

### Step 7: Apply and Validate

1. Backup existing config
2. Update shell rc file
3. Reload configuration
4. Test one alias

## Integration with tmux-project

The `/tmux-setup` command generates port mappings that `tmux-project` uses:

```bash
# In tmux-project, ports are read from:
# 1. Hardcoded PROJECT_PORTS array
# 2. TMUX_CLAUDE_PORTS environment variable
# 3. ~/.config/tmux-claude/ports.json

get_port() {
    local name="$1"
    # Check env var first
    if [ -n "$TMUX_CLAUDE_PORTS" ]; then
        echo "$TMUX_CLAUDE_PORTS" | jq -r ".[\"$name\"] // 0"
    else
        echo "${PROJECT_PORTS[$name]:-0}"
    fi
}
```

## Notes

- This command is idempotent - running it again updates the config
- Old aliases are removed before adding new ones
- Ports are checked for conflicts before assignment
- Works with both zsh and bash
